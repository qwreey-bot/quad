## 한 일

- **`Handlers/Event.luau`** — 문자열 키 ∧ 클래스 이벤트 집합 멤버. `v == nil`
  이면 `Void`(event-plan "이벤트도 store-bind 가능" — `None` 재귀가 `nil`로
  도착, NilHandler는 숫자 키 전용). 아니면 `inst[k]:Connect(v)` — 사용자
  함수를 감싸지 않고 그대로(self 미전달 1절), retractor가 Connection 캡처.
  **같은-값 dedup은 두지 않았다**: `Connect`는 비멱등이라 InstanceChild형
  편측 retractor skip은 이중 연결을 만들고, 대칭으로 하려면 "이미 연결됨"
  표식이 필요(새 구조) — event-plan이 재발행 churn을 허용하므로 구조를 안
  쓴다(설계 원칙 첫 항목). 값 타입 가드도 없음(Property와 같은 자세 — 엔진
  에러, `D` 타입이 시그니처를 찍는다).
- **`Handlers/OnChange.luau`** — `OnChange(name)` 이름별 weak 캐시(AttributeKey
  기법 그대로) + 키 브랜드는 **모듈 로컬 weak-key 집합**(quad-roblox가
  quad-base `Brand`를 require하지 않는 round14 Q3 (a) 유지). 핸들러는 키
  매치, `H-27` 얼리리턴, `GetPropertyChangedSignal(name):Connect(function()
  v(inst[name]) end)`. 에러 네임스페이스는 첫 설치 때 빌려둔다(팩토리가 모듈
  레벨이라).
- **표면** — `RobloxFactory`가 둘을 설치하고 확장을 `{ D, OnChange }`로
  반환(`UseProvider` 병합 → `q.OnChange` 풀 타이핑), `types.luau`에
  `OnChangeKey = { read Name: string }`, `init.luau` 재익스포트.
- **mock** — `mock.declareEvents(className, names)` 한 레지스트리에서
  `inst[name]`(지연 생성 Signal, 인스턴스별)과 `gameShim`의
  `GetEventsOfClass`가 같이 나온다(실물처럼 둘이 어긋날 수 없게).
- **spec** — `quad-roblox/test/spec.events.luau` 6절(인자 그대로 / 클래스별
  판별 / Event store-bind None·재연결·평문 교체·철거 / OnChange 값·캐시·
  blame / `H-27` / 교대·quad 간 키 공유). `spec.handlers`·`spec.claim`은
  문자열 키가 이제 Event 리플렉션도 지나므로 같은 심을 Event 모듈 env에도
  주입.
- **Studio 8/8** — 이벤트 인자 `argc=1`(self 없음), OnChange 새 값, `None`
  구간 무호출·무에러, 동등성, blame, no-match 둘. Deferred 관측 둘(콜백은
  배달 시점 값을 읽음 / 끊긴 Connection의 대기 배달은 드롭)은 엔진 특성으로
